vol.3 定義域つき二次関数
頂点が区間より
「右」にある時？
1 ≦ x ≦ 3 のとき
g(x) = x² − 8x + 15
の最小値・最大値を求めよ
頂点は x = 4。
区間 [1, 3] の右外にある。
今度はどちらが最小・最大になる？
① 情報の整理
求めたいもの：最小値・最大値
与えられてるもの g(x) = x²−8x+15 = (x−4)²−1
区間 : 1 ≦ x ≦ 3 （端点 x=1, x=3）
上に開く。軸 x = 4、頂点 (4, −1)
x=4 は [1, 3] の右外にある
軸が区間の右外 →
区間内では単調減少（x 大 → g(x) 小）
② 連想すること
― 最小について
軸 x=4 が [1,3] の右外
→ 区間内は全て軸より左 → 単調減少
↓最も大きい x = 最小
右端 x = 3 で最小
g(3) = (3−4)²−1 = 1−1 = 0
最小値 0　← 右端 x=3 で達成
② 連想すること
― 最大について
単調減少 → x が小さいほど g(x) が大きい
区間内で最も小さい x は？
↓左端が候補
左端 x = 1 で最大
g(1) = (1−4)²−1 = 9−1 = 8
最大値 8　← 左端 x=1 で達成
③ 方針の立案
最小値 0 　x=3（右端）で達成
最大値 8 　x=1（左端）で達成
単調減少だから
→ 左右が逆転する（左端＝最大）
④ 答案作成
g(x) = (x−4)²−1
1 ≦ x ≦ 3 において 軸 x=4 は区間外（右）
→ 区間内で単調減少
よって
x = 3 のとき　最小値 0
x = 1 のとき　最大値 8
「軸が区間外（右）」→ 単調減少
→ 右端＝最小、左端＝最大
[まとめ]　頂点が区間外（右）
軸が右外 → 区間内で単調減少
最小：右端 x=3　値 = 0
最大：左端 x=1　値 = 8
→ 前回（左外）と最小・最大が逆
軸が左外 → 単調増加（左端＝最小）
軸が右外 → 単調減少（右端＝最小）
①で軸位置確認 → ②連想 → ③方針
次回：a＜0（下に開く）のとき →
最小・最大の考え方が全部ひっくり返る。
