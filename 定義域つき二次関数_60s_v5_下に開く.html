vol.4 定義域つき二次関数
a が負になったら
全部ひっくり返る
1 ≦ x ≦ 6 のとき
h(x) = −x² + 6x − 5
の最小値・最大値を求めよ
a = −1 ＜ 0 → 下に開く
頂点が「最大」になる。最小はどこ？
① 情報の整理
求めたいもの：最小値・最大値
与えられてるもの h(x) = −x²+6x−5 = −(x−3)²+4
区間 : 1 ≦ x ≦ 6 （端点 x=1, x=6）
下に開く（a=−1）。軸 x = 3、頂点 (3, 4)
x=3 は [1, 6] の区間内にある
a＜0 → 頂点が最大
最小は「軸から遠い端点」で達成
② 連想すること
― 最大について（a＜0）
下に開く → 軸に近いほど大きい
頂点 x=3 が区間内にある
↓頂点を区間内で達成できる
頂点 x = 3 で最大
h(3) = −(3−3)²+4 = 4
最大値 4　← 頂点 x=3 で達成
② 連想すること
― 最小について（a＜0）
下に開く → 軸から遠いほど小さい
端点 x=1 と x=6 のどちらが遠い？
↓軸 x=3 との距離を比較
|1−3| = 2　|6−3| = 3
→ 右端 x=6 の方が遠い → 最小は x=6
h(6) = −36+36−5 = −5
最小値 −5　← 右端 x=6 で達成
③ 方針の立案
最大値 4 　x=3（頂点）で達成
最小値 −5 　x=6（遠い端点）で達成
a＜0 でも②の連想の流れは同じ
→ 最大と最小が入れ替わるだけ
④ 答案作成
h(x) = −(x−3)² + 4
1 ≦ x ≦ 6 において 軸 x=3 は区間内
かつ a＜0（下に開く）
よって
x = 3 のとき　最大値 4
x = 6 のとき　最小値 −5
（h(1)=0 ＞ h(6)=−5 より 遠い右端）
a＜0 → 最大と最小が入れ替わるだけ
考え方の枠組みは変わらない
[まとめ]　a ＜ 0 のとき
下に開く → 頂点が最大
最大：頂点 x=3　値 = 4
最小：軸から遠い端点 x=6　値 = −5
→ a＞0 のときと最大・最小が逆
a の符号で「頂点 = 最大 or 最小」が変わる
それ以外の連想ステップは同じ
①符号確認 → ②連想 → ③方針 → ④答案
シリーズ完結。全4パターン：
頂点内側 / 頂点左外 / 頂点右外 / a＜0
→ 軸の位置と符号を確認するだけ。
