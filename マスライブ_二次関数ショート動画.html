まず：区間なしの場合
頂点だけ見ればOK。
y = x²
y = (x−p)²+q
y = −x²
y = −(x−p)²+q
区間がなければ、答えは 頂点だけ。
でも、区間がつくと…？
f(x) = (x − a)²
x − a → x と軸 a の 距離
(x − a)² → 距離の 2乗
最大最小は、
「軸との距離」
だけで決まる。
①軸が動く
②区間が動く
ルールは同じ。
Part A : 軸が動く
f(x) = (x − a)² ／ 0 ≤ x ≤ 2
軸が区間の左にある
最小：近い端 x = 0　値 a²
最大：遠い端 x = 2　値 (2−a)²
Part A : 軸が動く
a が区間内をスライド
軸が区間内に入った
最小：頂点 x = a（値 0）
最大：軸から 遠い端
Part A : 軸が動く
a > 2 へ抜ける
軸が区間の右にある
最小：近い端 x = 2　値 (2−a)²
最大：遠い端 x = 0　値 a²
Part A まとめ
最大
＝ 遠い端
最小
＝ 近い端 or 頂点
Part B : 区間が動く
f(x) = x² ／ t−1 ≤ x ≤ t+1
区間が軸の左に外れた
最小：近い右端 x = t+1
最大：遠い左端 x = t−1
Part B : 区間が動く
軸が区間に飲み込まれる
軸が区間内
最小：頂点 x = 0
最大：軸から 遠い端
Part B : 区間が動く
区間が右に抜ける
区間が軸の右に外れた
最小：近い左端 x = t−1
最大：遠い右端 x = t+1
Part B まとめ
最大
＝ 遠い端
最小
＝ 近い端 or 頂点
…さっきと同じ。
動くのが軸でも区間でも
軸が動く
区間が動く
見るのは
「軸との距離」
だけ。
