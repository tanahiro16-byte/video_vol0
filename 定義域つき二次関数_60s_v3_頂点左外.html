// vol.2 定義域つき二次関数
頂点が区間より
「左」にある時？
2 ≦ x ≦ 5 のとき
f(x) = x² − 2x + 3
の最小値・最大値を求めよ
頂点は x = 1。
区間 [2, 5] の外（左）にある。
こういう時、どこが最小・最大？
① 情報の整理
求めたいもの：最小値・最大値
与えられてるもの f(x) = x²−2x+3 = (x−1)²+2
区間 : 2 ≦ x ≦ 5 （端点 x=2, x=5）
上に開く。軸 x = 1、頂点 (1, 2)
x=1 は [2, 5] の左外
軸が区間の左外 →
区間内では単調増加（x 大 → f(x) 大）
② 連想すること
― 最小について
軸 x=1 が [2,5] の左外
→ 区間内は全て軸より右 → 単調増加
↓最も小さい x = 最小
左端 x = 2 で最小
f(2) = (2−1)² + 2 = 3
最小値 3　← 左端 x=2 で達成
② 連想すること
― 最大について
単調増加 → x が大きいほど f(x) も大きい
区間内で最も大きい x は？
↓右端が候補
右端 x = 5 で最大
f(5) = (5−1)² + 2 = 16 + 2 = 18
最大値 18　← 右端 x=5 で達成
③ 方針の立案
最小値 3 　x=2（左端）で達成
最大値 18 　x=5（右端）で達成
単調増加だから
→ 両端の計算だけで決まる
④ 答案作成
f(x) = (x−1)² + 2
2 ≦ x ≦ 5 において 軸 x=1 は区間外（左）
→ 区間内で単調増加
よって
x = 2 のとき　最小値 3
x = 5 のとき　最大値 18
「軸が区間外（左）」→ 単調増加
→ 左端＝最小、右端＝最大
[まとめ]　頂点が区間外（左）
軸が左外 → 区間内で単調増加
最小：左端 x=2　値 = 3
最大：右端 x=5　値 = 18
①で「軸の位置」を確認（左外か？）
②で「単調増加 → 両端で決まる」を連想
③方針 → ④答案
次回：頂点が区間外（右）→
今度は単調減少。最小・最大が逆になる。
