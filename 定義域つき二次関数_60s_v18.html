なぜ手が止まる？

定義域に
文字が入ると
場合分けが
わからなくなる

解法じゃなく、発想の流れが大事

問題
a を正の定数とする。
0 ≦ x ≦ a のとき

f(x) = x² − 4x + 5

の最小値・最大値を求めよ。
a が変わると
軸と定義域の位置関係が変わる
それが場合分けの正体
基礎確認
最小 = 頂点　軸に一番近い点
最大 = 軸から遠い端点

この2つが問題全体の土台

情報の整理
情報 1
f(x) = (x−2)²+1
→ 軸 x = 2、頂点 (2, 1)
▶ 軸の位置がわかる
情報 2
定義域 0≦x≦a → 端点は x=0 と x=a
軸から遠い方が最大になるから両端の値を出す
f(0) = 5　f(a) = a²−4a+5
▶ 最大の候補値が特定できる
最小値　連想
情報 1 → 軸が x=2 にある
情報 2 → 定義域の右端が x=a
合わせると：軸が定義域に入るかどうかは a 次第
連想 1
a < 2　軸が外 → 右端が最小
a ≧ 2　軸が中 → 頂点が最小
→ 境界は a = 2
最小値　答案
連想 1 が決まったから方針が立てられる。境界は a = 2 だ。
0 < a < 2（軸が外）
最小値 = a² − 4a + 5（右端）
a ≧ 2（軸が中）
最小値 = 1（頂点 x=2）
場合分けは連想 1 から自然に出てくる
最大値　連想
情報 1 → 軸が x=2
情報 2 → 端点が x=0 と x=a
合わせると：どちらの端点が軸から遠いか
連想 2
x=0 まで距離 2　x=a まで距離 a−2
逆転するのは a−2 = 2 → a = 4 が境界
最大値　答案
連想 2 が決まったから方針が立てられる。境界は a = 4 だ。
0 < a ≦ 4（左端が遠い）
最大値 = 5（x=0）
a > 4（右端が遠い）
最大値 = a² − 4a + 5
場合分けは連想 2 から自然に出てくる
まとめ
最小値のポイント
軸が定義域に入るかどうかで決まる
→ 境界 a=2 は情報 1 から導ける
最大値のポイント
端点が軸からどちらが遠いかで決まる
→ 境界 a=4 は情報 2 から導ける
条件を整理して連想するだけ。
場合分けは暗記するものじゃなく、条件から導くもの。
